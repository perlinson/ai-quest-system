## 📄 模板示例

### 代码审查Prompt
```
## 角色
你是一位资深代码审查专家

## 任务
审查以下代码，找出潜在问题：

[粘贴代码]

## 审查维度
1. 安全性
2. 性能
3. 可读性
4. 最佳实践
5. 潜在Bug

## 输出格式
| 文件 | 问题 | 严重程度 | 建议 |
```

### 技术文档Prompt
```
## 角色
你是一位技术文档专家

## 任务
为以下项目编写技术文档：

项目描述：[描述]
技术栈：[技术列表]
目标读者：[读者群体]

## 要求
1. 清晰简洁
2. 包含示例
3. 易于维护

## 输出格式
1. 概述
2. 安装指南
3. 使用说明
4. API参考
5. 常见问题
```
